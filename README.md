Brainrot Big Top — a 3D circus tycoon for make.fun's "Make the best AI Roblox brainrot game" bounty. Twelve original circus acts parade around the big top, each earning money a second; buy them, seat them on your ring, lock the ring against thieves, slap the thieves who try anyway, and climb the Rebirth ladder while the Elephant Stampede, the Big Top Hour, the Confetti Storm and the Giant Claw keep the show moving. With a BrainrotDex, a Contract Board, Offline Earnings and Daily Rewards.

## Run it

```sh
rojo build default.project.json --output game.rbxl
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
